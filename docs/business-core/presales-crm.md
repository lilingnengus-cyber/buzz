# 简洁售前 CRM

入口：企业工作台「售前 CRM」独立分组，与「业务闭环」同级，下设「商机」「跟进记录」「客户联系人」。商机保留 `/#crm`；跟进记录为 `/#crmFollowups`，客户联系人为 `/#crmContacts`，对应嵌入路径 `/embed/crm`、`/embed/crm/followups`、`/embed/crm/contacts`。

企业客户售前采用商机列表和详情页，并提供独立的跟进历史和客户联系人页面。阶段为新线索、沟通中、报价中、已成交、已流失。可以填写潜在客户公司和联系人，或关联有权限访问的已有客户。每次跟进保留沟通内容、作者、时间、当时阶段和下一步；下次跟进日期支持「今天及逾期」筛选。预计金额可为空；已成交/已流失不进入待跟进筛选。成交后可转到现有销售订单模块手工录单。

这是 Business Core 的业务扩展，复用其既有 HttpOnly 会话、同源/CSRF 检查、操作限流和 PostgreSQL。没有新增 Relay HTTP API，也没有浏览器本地数据冒充持久化。当前不包含聊天 Agent 工具、自动建销售订单、报价单、营销自动化或提醒推送。

## 数据与访问

迁移 `0034_presales_crm.sql` 创建 `crm_opportunities`、`crm_followups`；不修改订单、库存、应收。`crm:read` / `crm:manage` 授予现有 Business Core 的 `business_admin`、`s1_operator` 角色；IAM 目录登记能力但不自动授予 IAM 主体。访问仍必须命中法人主体、业务单元以及已关联客户的当前数据范围。新商机默认由当前账号负责；初版同范围的有权用户共享访问，没有另设负责人分配体系。

主体创建后固定。关联客户必须归属同一法人和业务单元。主数据停用后不能创建/保存引用它的新内容，但旧商机和跟进历史仍可在授权范围内查看。所有修改使用现有命令幂等表、版本检查、审计与 outbox，同一事务保存跟进和下一步。浏览器在不确定网络结果后的相同内容重试复用幂等键；改变内容会生成新键。没有删除入口。

列表先过滤权限，再做文本/阶段/跟进日期筛选和 50 条分页。搜索把 `%` 等字符作为字面量。跟进历史每页 100 条，可查看更早记录。下次跟进按浏览器本地日历日期比较，避免 UTC 跨天偏移；这是待办筛选，不会自动发送提醒。

## CRM 页面分组

跨商机跟进记录由 `GET /api/v1/crm/followups` 读取，按创建时间倒序显示；联系人由 `GET /api/v1/crm/contacts` 汇总现有商机联系人，不建立重复主数据。只有同一法人、业务单元、关联客户、公司、姓名和联系方式完全相同的记录才合并显示，保留全部关联商机链接。联系人通过关联商机编辑，不提供独立的新建/删除。

两个列表均在服务端先应用 crm:read 和当前数据范围，再搜索及每页 50 条分页。跟进记录可搜沟通内容，联系人可搜联系方式。链接 `/#crm?opportunity=<id>` 打开相应详情；原 `/#crm` 入口继续有效。没有数据库迁移或历史数据改写。

## 2026-10-02 独立档案与跟进安排

当前实现以本节为准，替代初版联系人从商机文字汇总、不能独立维护的限制。

- 保留三个导航入口；“客户联系人”内分别维护客户档案和联系人。
- `crm_accounts` 为售前档案：潜在客户仅需名称；关联正式客户时以 `customer_id` 唯一引用核心客户，名称实时复用核心数据，不能在 CRM 重命名正式客户。不会自动创建交易客户或分配客户编码。
- `crm_contacts` 独立属于一个客户档案，可在没有商机时建立；商机通过 `account_id/contact_id` 引用。选择已有联系人时在商机中只读，统一从联系人页面修改。快速录入商机会在同一事务中解析或建立客户、联系人档案。
- 客户、联系人档案不绑定法人或经营单元。正式客户档案遵循当前客户数据授权；潜在客户的创建者，或能访问其关联商机的用户，可读取；修改还需 `crm:manage`。关联商机链接单独按法人、经营单元及客户权限过滤。不同创建者的同名潜在客户不会自动合并，以免跨权限范围混同。
- 迁移 77 保留原商机及其原始文字，建立档案关联；正式客户按核心 ID 合并，潜在客户按创建者与规范化名称合并，联系人按档案、姓名、联系方式合并。读取视图显示当前档案值，跟进原文不改写。
- 档案修改使用版本、幂等键和审计；联系人或客户修改同步提升关联商机版本，避免旧页面覆盖新资料。不提供删除或自动合并入口。
- 商机默认筛选“进行中”，支持逾期、今天、未来七天（明天起至第七天）、未安排、全部。筛选在权限过滤后、分页前进行，以客户端本地日历日为基准；选择成交/流失阶段自动切换为全部跟进安排。
- 商机、跟进及档案编辑抽屉支持未保存提示，覆盖关闭按钮、外部点击、Esc、表单取消、详情转编辑及页面刷新；保存失败保留输入，保存期间禁止关闭。
