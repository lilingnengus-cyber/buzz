# ADR 022：核心主数据采用不可变编码与停用影响检查

## 状态

已接受。

## 决策

法定主体、经营主体、客户、供应商和仓库共享一套受控维护协议。编码创建后不可变；客户、供应商和仓库是集团共享主数据，不绑定法定主体或经营主体。经营单元自身的父级可按组织树移动规则调整。业务单据独立保存法定主体与经营单元，历史业务事实不回写。属性修订使用乐观版本；已被引用的记录退出使用可逆的 `disabled` 状态；未被引用的记录允许带版本校验的受控删除，并保留审计事件。执行停用前，服务必须从订单、库存、往来和盘点等权威业务表实时计算影响，并在任何阻断事实存在时拒绝命令。

## 原因

这些记录已经被销售、采购、库存和经营报表共同引用。允许换码或直接删除会改变历史事实含义；把法定主体、经营单元留在主数据上还会错误限制跨主体复用。把规则放在领域服务内，可让页面、自动化和未来客户端共享同一安全边界。

## 后果

- 客户、供应商和仓库可跨法定主体与经营单元复用；每张业务单据仍必须按其领域规则选择并校验自己的法定主体与经营单元。
- 历史业务继续展示停用对象，新的业务选择器只提供启用对象。
- 停用检查可能随实时业务变化，因此确认命令会再次执行检查，不能只信任预览结果。
