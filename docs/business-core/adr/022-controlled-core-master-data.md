# ADR 022：核心主数据采用不可变编码与停用影响检查

## 状态

已接受。

## 决策

法定主体、经营主体、客户、供应商和仓库共享一套受控维护协议。编码与法定主体创建后不可变；客户的经营主体作为当前默认/管理归属，允许在操作者有权访问的启用经营单元之间受控调整，历史业务事实不回写。经营单元自身的父级可按组织树移动规则调整，其他对象归属保持不可变。属性修订使用乐观版本；退出使用可逆的 `disabled` 状态而非删除。执行停用前，服务必须从订单、库存、往来和盘点等权威业务表实时计算影响，并在任何阻断事实存在时拒绝命令。

## 原因

这些记录已经被销售、采购、库存和经营报表共同引用。允许换码、迁移归属或直接删除会改变历史事实含义；只在页面提示影响又无法防止并发或绕过。把规则放在领域服务内，可让页面、自动化和未来客户端共享同一安全边界。

## 后果

- 客户可以调整当前经营主体；历史单据继续保留原始经营单元。其他业务对象纠正错误归属时需要停用旧记录并新建正确记录。
- 历史业务继续展示停用对象，新的业务选择器只提供启用对象。
- 停用检查可能随实时业务变化，因此确认命令会再次执行检查，不能只信任预览结果。
