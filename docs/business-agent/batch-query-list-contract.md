# BizOS 批量查询列表契约

批量查询列表用于订单、收付款和库存等多条结果的快速扫读。

每项固定按“业务编号｜状态｜金额／数量｜业务日期｜详情链接”顺序展示，只有工具实际返回且适用的字段才显示；不展示内部 UUID，并保持服务器返回顺序。状态、金额／数量与业务日期必须逐项呈现，不能只在开头汇总；同一状态可在每项重复。

分页未完成时明确“截断”并说明仍有更多结果；工具返回 `partial` 时明确“部分结果”。当前页不能冒充完整结果。

自动契约测试位于 `crates/buzz-acp/src/business_agent/tests.rs`。
