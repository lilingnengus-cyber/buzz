# BizOS 查询结果说明契约

本契约统一无结果、部分结果和权限受限时的 BizOS 回复，避免把范围有限的结果说成绝对事实。

## 固定结构

使用“查询结果说明”，依次展示：

1. 结论；
2. 查询范围；
3. 完整性；
4. 工具返回的已验证原因；
5. 查询记录；
6. 追踪号；
7. 一个下一步建议。

仅在字段由服务器返回时展示。不展示内部 UUID，不推断记录不存在，也不补造范围、完整性、原因、链接或追踪号。

## 三类结果

- 完整空查询：说“当前范围内没有匹配项”，并保留查询范围和完整性。
- 部分结果：说“部分结果”，说明已验证原因和未完成的范围，不能据此建立唯一匹配或断言无记录。
- 精确读取权限受限：只说“未找到或无权访问”，保持合并表述。

工具包含 `agent_query` 时提供“查询记录”；有 trace ID 时最终一行写“追踪号”。下一步建议必须基于当前能力，例如继续读取下一页、调整筛选条件或由有权限人员查看；不能建议绕过权限。

自动契约测试位于 `crates/buzz-acp/src/business_agent/tests.rs`。
