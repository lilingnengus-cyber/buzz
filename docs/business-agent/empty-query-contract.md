# BizOS 空查询结果契约

本契约统一中文 BizOS 对“没有返回项目”的说明。空数组本身不证明记录不存在；回复必须结合工具状态、权威分页字段、完整性警告和查询类型判断。

## 精确资源路由

当用户明确提供销售订单的 UUID 作为精确资源标识时，BizOS 必须调用 `get_sales_order`，不得改用 `search_sales_orders`。名称、业务编号或其他非 UUID 条件才走搜索工具。这样 `not_found_or_forbidden` 保持为精确读取的合并访问结果，不会被错误改写为搜索范围内没有匹配项。

## 状态矩阵

| 工具结果 | 用户可见措辞 | 后续行为 |
| --- | --- | --- |
| `status=ok`、`items=[]`、`pagination.hasMore=false`，且没有影响完整性的警告 | “当前范围内没有匹配项” | 说明筛选范围、数据时点和查询记录；不能把空数组解释为记录不存在 |
| `status=ok`、`items=[]`、`pagination.hasMore=true` | “当前页没有可见结果，仍有更多数据待读取” | 用户要求全部结果、判断唯一匹配或为写入解析对象时，继续读取下一页 |
| `status=partial` 或存在影响完整性的警告，且 `items=[]` | “部分结果暂未返回可展示数据” | 说明已验证的警告或缺失范围，不把它说成完整的空结果 |
| `status=ok`、`items=[]`，但权威分页字段缺失 | “当前未返回可展示数据，完整性未由工具说明” | 不推断查询已经结束，也不推断总数 |
| 精确资源读取返回 `not_found_or_forbidden` | “未找到或无权访问” | 保持合并表述，不判断资源是否存在，不泄露权限过滤事实 |
| 查询失败或上游服务不可用 | 说明查询未完成和已验证原因 | 不能把失败改写成“没有匹配项” |

## 完整性和隐私边界

- 委托范围过滤可能令当前可见页为空，同时保留 `pagination.hasMore=true`。这时必须继续读取下一页，不能建立唯一匹配，也不能声称没有结果。
- 只有在 `status=ok`、权威分页明确结束且没有影响完整性的警告时，才能把 `items=[]` 表述为当前搜索范围内没有匹配项。
- “当前范围内没有匹配项”只描述本次条件和授权范围，不表示业务系统全局没有该记录，也不披露被过滤对象或数量。
- 不透明游标、内部 UUID、权限策略和被过滤数量不进入回复。不能从空页、页数或游标推断总数。
- `resourceRefs` 为空时不要生成资源链接；工具提供 `agent_query` 时保留准确的“查询记录”，提供 trace ID 时保留末尾追踪号。
- “追踪号”只能逐字复制当前工具结果明确提供的 trace ID。用户输入的订单 UUID、业务编号、资源 ID、查询条件和来源事件 ID 都不能作为追踪号；工具没有返回 trace ID 时省略整行，不要猜测、回填或复用格式相似的 UUID。

## 零值不是空结果

没有结果不等于零值。已返回记录中的金额 `0`、数量 `0`、比率 `0` 或计数 `0` 都是业务数据，必须按各字段显示契约呈现，例如 `CNY 0.00`、`0.00 件` 或 `0%`。缺失值、不可用值和空结果不能改写成零。

## 回复示例

完整空结果：

> 当前授权范围内，客户名称“默认客户”没有匹配项。数据时点：2026-09-24 10:00（UTC+8）。
>
> [查询记录](biz://agent-query/server-returned-id)
>
> 追踪号：server-returned-trace-id

空页但仍有后续页：

> 当前页没有可见结果，仍有更多数据待读取。我会继续读取下一页后再判断是否存在唯一匹配。

部分结果为空：

> 部分结果暂未返回可展示数据：上游同步不完整。当前结果不能用于判断没有匹配项。

精确读取受保护：

> 该资源未找到或无权访问。
